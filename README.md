# homebrew-teru

Homebrew tap for [teru](https://github.com/nicholasglazer/teru) -- AI-first terminal emulator, multiplexer, and tiling manager.

## Install

```bash
brew install nicholasglazer/teru/teru
```

Or add the tap first:

```bash
brew tap nicholasglazer/teru
brew install teru
```

## Update

```bash
brew upgrade teru
```

## About teru

One binary. No GPU. 1.4MB. Built-in multiplexer, 8 tiling layouts, AI agent protocol, MCP server.

- [GitHub](https://github.com/nicholasglazer/teru)
